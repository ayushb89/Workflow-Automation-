This repository contains BPMN process models for three scenarios, created using Camunda Modeler.

## Scenarios

1. **Employee Leave Approval** – models the flow of an employee applying for leave, including leave balance check and manager approval.
2. **Online Purchase Order Processing** – models an online order from placement through payment, shipment, and delivery confirmation.
3. **IT Service Request** – models how an employee's IT issue is registered, assigned, resolved or escalated, and closed.

## Contents

- **Report** – explains each scenario and its corresponding BPMN process, with diagram screenshots.
- **Diagrams** – image exports of the three BPMN models.
- **Model files (.bpmn)** – the actual BPMN 2.0 XML files, viewable and editable in Camunda Modeler.

## How to view the models

Open any `.bpmn` file in [Camunda Modeler](https://camunda.com/download/modeler/) (File → Open File) to see the diagram.
